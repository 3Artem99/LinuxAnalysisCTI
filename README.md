# LinuxAnalysisCTI

## Курсовая работа 11 семестра

### Тема работы

Исследование методов выявления признаков кибератак на ОС Linux на основе анализа системных журналов и информации из открытых источников.

### Цель работы

Исследовать методы выявления признаков кибератак на операционную систему Linux на основе анализа системных журналов и сопоставления зарегистрированных событий с информацией о киберугрозах из открытых источников. Провести экспериментальное исследование на тестовых данных, оценить возможности и ограничения рассматриваемых методов и разработать рекомендации по их применению для повышения защищённости ОС Linux.

### Задачи

- Изучить основные механизмы регистрации событий безопасности в ОС Linux и рассмотреть возможности использования системных журналов для выявления признаков кибератак
- Проанализировать существующие открытые источники информации о киберугрозах и методы получения сведений об индикаторах компрометации (IoC)
- Исследовать методы сопоставления событий из системных журналов с известными индикаторами компрометации и рассмотреть существующие средства для выполнения такого анализа
- Провести экспериментальное исследование на тестовых данных: проанализировать системные журналы, сопоставить обнаруженные сведения с информацией из открытых источников и оценить результаты выявления потенциальных угроз
- Оценить возможности и ограничения рассмотренного подхода и разработать рекомендации по его применению для повышения защищённости ОС Linux

### План выполнения работы

1. Будет изучена структура системных журналов Linux и рассмотрены механизмы регистрации событий безопасности, в частности событий аутентификации SSH
2. Будут выбраны открытые источники информации о киберугрозах и исследованы способы получения сведений об индикаторах компрометации (IP-адресах, доменах и других сетевых индикаторах)
3. Будет подготовлен набор тестовых журналов Linux, содержащий примеры событий, связанных с успешными и неудачными попытками аутентификации и другой подозрительной активностью
4. Будет проведено сопоставление сведений из системных журналов с информацией об известных киберугрозах из открытых источников
5. Будут проанализированы результаты сопоставления, оценены возможности выявления потенциальных угроз и ограничения используемых источников
6. По результатам исследования будут сформулированы рекомендации по применению открытых источников для выявления признаков кибератак на ОС Linux

### Используемые инструменты

- Linux / Ubuntu — исследуемая операционная система и тестовая среда
- journalctl и системные журналы — получение и анализ событий ОС
- VirusTotal, URLhaus и/или AbuseIPDB — получение информации об индикаторах киберугроз
- LibreOffice Calc или Microsoft Excel — систематизация данных и анализ результатов эксперимента

Окончательный набор инструментов будет определён в ходе исследования.

### Ожидаемые результаты

- Описание методики выявления признаков кибератак на основе системных журналов и открытых источников
- Сравнительная таблица выбранных источников информации о киберугрозах
- Результаты экспериментального сопоставления системных событий с индикаторами компрометации
- Оценка возможностей и ограничений рассмотренного подхода
- Практические рекомендации по выявлению признаков кибератак на ОС Linux

Исследование проводится в учебных целях с использованием тестовых данных и собственной лабораторной среды.
